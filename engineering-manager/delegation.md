### Skill/Fun Task Delegation Matrix | PDF - Scribd
#
Skill/Fun Task Delegation Matrix
The document describes a skill/fun matrix for ranking tasks based on their required skill level and interest level.
Users are instructed to log all tasks for a week and rank them as high, medium, or low on those scales.
Tasks that are low interest and low skill should be delegated.
The user should then work to delegate other tasks moving up the matrix from low interest/skill to higher levels.
