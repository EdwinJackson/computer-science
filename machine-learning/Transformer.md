Transformers are a type of [[Machine Learning]] model that can learn from data without being explicitly programmed. They are used in natural language processing and computer vision. The self-attention mechanism is a mathematical technique that helps transformers learn context and understanding through sequential data analysis.

![[transformer-simplified.png]]

A transformer is a deep learning model that adopts the mechanism of self-attention, differentially weighting the significance of each part of the input data. It is used primarily in the fields of natural language processing (NLP) and computer vision (CV).   

Transformers are neural networks that learn context and understanding through sequential data analysis. The Transformer models use a modern and evolving mathematical techniques set, generally known as attention or self-attention. This set helps identify how distant data elements influence and depend on one another.

This was all outlined in the paper [Attention Is All You Need](https://arxiv.org/abs/1706.03762)
