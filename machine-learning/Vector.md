An array of data elements of the same type. Vectors are used to store and manipulate collections of data that are ordered and indexed

In Python, this is an array but is not a vector because there is no type guarantee.
```python
[None, 2, 'three']
```

This is a vector because every collection member has the same type.
```python
[1.001, -0.456, 0.1293, 0.00342]
```
