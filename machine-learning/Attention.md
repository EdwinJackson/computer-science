Attention is a mechanism that allows the model to focus on certain parts of the input sequence when computing the output sequence. The [[Transformer]] model revolutionized the implementation of attention by dispensing with recurrence and convolutions and, alternatively, relying solely on a self-attention mechanism². The Transformer implements scaled dot-product attention, which follows the procedure of the general attention mechanism that you had previously seen. As the name suggests, the scaled dot-product attention first computes a dot product for each query with all of the keys². There are three different attention mechanisms in the Transformer architecture. One is between the encoder and the decoder. This type of attention is called cross-attention since keys and values are generated by a different sequence than queries³.

## How does an Attention Layer Work

Attention layers are found in the encoder and the decoder part of the Transformer. Later, I’ll describe where these layers fit within the Transformer architecture.

Before reaching the attention layer, the input text is first tokenized to representative embeddings. From each embedding, the encoder will produce representative encodings using attention, and the decoder will do the opposite, outputting text.

## Attention Layer 
There are 4 steps in the Attention Layer. 

### First Step
First, we need to create embeddings, that are vectors that can be classified as queries, keys, or values. 

- **Query** - The information that is being looked for
- **Key** - The context or reference
- **Value** - The context that is being searched
